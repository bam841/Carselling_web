# Car Selling Business Website

A modern car dealership & vehicle sales website designed in **Relume** and built in **Webflow** using the Finsweet Client-First style system.

---

## 🔗 Project Links
- **Relume Project:** [Relume App Site](https://www.relume.ai/app/site/01a17605-cbf5-7bfb-a204-cddde73b3aa8)
- **Webflow Site:** Cloned from the [Relume Style Guide v3](https://webflow.com/made-in-webflow/website/relume-style-guide-v3)

---

## 📁 Folder Structure
```text
car-selling-website/

├── data/
```

---

## 🚀 Workflow & Build Instructions
1. **Relume Design:** Wireframes, sitemap, and page structure generated via Relume.
2. **MCP Integration:** Connected through **Relume Publish MCP** and **Webflow MCP**.
3. **Webflow Execution:** Elements, components, and responsive layouts constructed onto the Relume Style Guide base canvas.
